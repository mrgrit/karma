# v0.5.2 — 진급 속도·게임 닉네임·글자 크기 수정

- 진급 누적 경험치를 10배로 조정했습니다: 훈련병 0, 이병 1,000, 상병 3,000, 병장 6,000, 소위 10,000 XP. 캐릭터 해금과 병장 쌍포 조건도 같은 계급에 맞췄습니다.
- 기존 경험치와 전적, 코인, 경험치 획득량은 유지됩니다. 계급과 사용 가능한 장비 예산은 새 기준으로 계산합니다.
- 게임 HUD와 Shift 전적표에 원본 연습 모드의 `KampGrupe` 대신 계정 닉네임을 표시합니다. 한글 이름은 원본 게임의 CP949 문자 인코딩으로 전달하며 중간 참가자에게도 적용합니다.
- Windows 200% 배율에서 도움말·전적표 글자만 두 배로 커지는 문제를 수정했습니다. 원본 글꼴 생성에만 96 DPI 기준을 사용하며 게임 창과 마우스의 DPI 보정은 유지합니다.

클라이언트 전체 검사와 Windows/Linux 서버 전체 검사를 통과했습니다. 입력 장치를 점유하지 않는 원본 게임 검사에서 한글 로컬/상대 이름, HUD 이름, Shift/F1 입력 경로, 200% 데스크톱의 13/16픽셀 글꼴 생성을 확인했습니다.

기존 설치 위치에 v0.5.2 설치 파일을 실행하면 업데이트됩니다. 로그인과 개인 설정은 유지됩니다. 서버의 진급 기준은 관리자가 별도로 배포합니다.

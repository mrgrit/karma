# v0.8.1

중위부터 대장까지 9개 계급을 추가하고 게임 HUD·Shift 전적 화면에 원본 계급 아이콘을 표시합니다. 계급은 중앙 서버가 판정하며 장비 보너스는 소위와 같은 400점입니다.

장교 승급에는 누적 XP·기법 숙련과 검증 실전 경험이 필요합니다. 서버는 충분한 표본이 쌓이면 승급 속도를 주 1회 평가해 작은 범위에서 기준을 조정합니다. 대시보드 종합 현황의 승급 기준에서 현재 요건·진행 상황·변경 예고를 확인할 수 있습니다. 새 조건은 24시간 예고 후 적용하고 획득한 계급은 보존합니다.

서버 3.9.0과 함께 사용합니다. 운영 규정 `2026-10-27.1`에 직접 동의해야 대전에 참가할 수 있습니다. 0.8.0과 동일한 업데이트 서명키를 사용하므로 0.8.0 설치 사용자는 자동 업데이트가 가능합니다.

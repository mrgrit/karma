# v0.6.2 — 최종 결과, 종료 조건, Point, 전체·팀 채팅

- 경기 종료 후 승리·패배·무승부, 종료 이유, 참가자별 이름·킬·데스·Point를 표시합니다. 게임 진행과 입력은 멈추고 마우스를 해제합니다. 결과 창의 **퇴장**을 눌러 실행기로 돌아갑니다. 종료 후 서버 연결이 닫히는 정상 동작을 연결 오류로 처리하지 않습니다.
- 방 만들기에서 1:1·개인전은 **1~30킬**, 팀전은 **1~10라운드 승리**, 제한 시간은 **1~30분**으로 설정합니다. 기본값은 10킬·5승·10분입니다. 목표 점수와 시간 중 먼저 도달하면 끝납니다. 시간 종료 시 개인전은 최다 킬, 팀전은 최다 라운드 승리로 승패를 정하며 공동 선두는 무승부입니다.
- 방 목록의 선택 정보와 대기실에 종료 조건이 보입니다. 서버가 방장 설정을 검증하고 참가·중간 참가 때 같은 규칙을 전달합니다.
- Shift 전적표의 Point를 이번 경기에서 서버가 확정한 경험치로 갱신합니다. 기존 학과 규칙인 **확정 킬 25 XP · 사망 5 XP**를 그대로 사용합니다. 코인과 누적 계급 경험치는 별개입니다. 원본의 온라인 경험치 함수를 호출하지 않고 실제 숫자 표시 필드에 반영합니다. [분석·검증 근거](native-score-points.md)

- 대기실에서 채팅할 수 있습니다. 게임에서는 **T 전체 채팅 / Y 팀 채팅**, Enter로 전송 후 복귀, Esc로 닫기입니다. 최근 수신 메시지는 게임 화면에 표시됩니다. 팀전에서는 전체/팀 대상을 구분하고 서버가 같은 팀에게만 팀 메시지를 전달합니다. 채팅 중에도 대전은 계속됩니다.

기존 사용자는 게임과 실행기를 완전히 닫고 다시 열면 자동 업데이트됩니다. 두 PC 모두 최신 버전으로 실행하세요.

- 해킹 알림을 오른쪽 위에 최대 5줄, 7초 동안 표시합니다. 공격자 → 피격자 · 무기 이름과 Headshot을 구분하고 내 킬은 금색, 내 사망은 붉은색으로 보입니다. 서버가 확정한 치명타에만 표시하며 자멸/원인 미확인 사망을 구분합니다. 알림은 마우스와 키보드 입력을 가져가지 않습니다. [판정·표시 근거](native-kill-feed.md)

검증: 전체 클라이언트·서버 회귀 검사, 방별 상한/하한과 잘못된 입력 거부, 서로 다른 시간 제한, 중간 참가 규칙, 8인 개인전과 4:4 목표 승수 종료, 최종 K/D·이름·Point, WinForms 결과/설정 조작 검사. 원본 Factory 엔진 두 개의 격리 실행으로 서버 종료 통지→입력/세계/시계 정지→대기→명시적 퇴장을 확인했습니다. 원본 Shift 숫자 렌더러에서 Point 갱신도 확인했습니다. 모의 8인 결과를 실제 Windows 창으로 확인하고 퇴장했습니다. 수정본으로 학생 PC와 물리적인 두 PC 재대전은 별도 확인이 필요합니다.

- 전체/팀 채팅의 비속어는 서버에서 `***`로 마스킹합니다. 대기실·게임 중 전송되는 모든 채팅의 원문과 표시 내용을 서버에 보관하며, 게임 서버 대시보드의 **채팅 기록** 메뉴에서 관리자만 조회합니다. 기록은 자동 삭제하지 않습니다. 필터는 사전 기반으로 우회 표현을 모두 막지는 못하며 `chat-policy.json`으로 확장할 수 있습니다. 배포 이전의 채팅은 복구할 수 없습니다.

# v0.7.6 — F2 메뉴, 저장 알림, 코인 위치 수정

- F2를 누르면 종료되던 원본 설정 화면 대신 안전한 외부 메뉴를 엽니다. 마우스·화면 설정 버튼에서 이 PC의 옵션을 저장할 수 있습니다. 변경한 옵션은 다음 게임부터 적용됩니다.
- F12 저장 전에 미완성 파일명을 출력하던 원본 알림을 제거하고, JPEG 저장 후 `스크린샷 저장 완료: Data/ScreenShot`을 표시합니다.
- 내 코인은 캐릭터·체력 표시 아래로 이동합니다. 화면 크기에 맞춰 간격을 확보합니다.

검증: 원본 F2 충돌 재현 후 LAN/연습 입력 모듈 각각에서 두 차례 F2 입력과 생존·메뉴 이벤트를 확인했습니다. 실제 엔진 F12 캡처 두 장 및 한글 알림을 직접 확인했습니다. 기존 16개 클라이언트 테스트와 100~300% DPI HUD 배치 검증을 통과했습니다.

서버 계정과 전적은 변경하지 않습니다.

# v0.7.0 — 공격 기법 알림, 숙련 승급, 작은 무기 안내

서버 3.7.0과 함께 사용합니다.

- 서버가 확인한 처치 알림에 무기별 공격 기법을 표시합니다. 예: `A → B · Kar.98k 저격소총 · 링크 스피어피싱`.
- XP와 무기별 숙련을 모두 만족해야 승급합니다. 계급, 장비 예산, 캐릭터와 쌍포 해금은 서버가 전달한 실제 달성 계급을 사용합니다. 누적 XP는 그대로 표시합니다.
- 승급 기준과 계정별 진행 상황, 전체 성공/승급 인정 횟수는 웹 대시보드에서 확인합니다. 기존 계급은 서버 이전 시 보존합니다.
- 바닥 무기 안내가 코인 패널을 440×150 크기로 확장하던 동작을 제거했습니다. 화면 오른쪽 아래에 검은 배경 없이 코인 한 줄, 무기 안내 한 줄만 표시합니다.
- 접근 시 `[E] 무기명 · 장탄/예비탄`, 보유·점수 초과 상태와 짧은 결과를 표시합니다. 세부 점수 설명은 전투 중 표시하지 않습니다. 인접 안내는 0.9초 만료로 멀어진 뒤 빨리 사라집니다.
- 화면 크기에 맞춰 DPI를 제한하고, 긴 텍스트는 한 줄 말줄임으로 처리합니다. 마우스 통과 및 포커스 비활성 동작은 유지합니다.

검증: C# 빌드, 기본 클라이언트 검사 14개, 네이티브 수동 줍기 회귀, 숨김 WinForms 숙련/장비 예산/쌍포 검사, 100–300% DPI 배치와 투명 HUD 렌더링. 실제 원본 게임의 장시간 대전은 이번 변경 검증에 포함하지 않습니다.

이번 릴리즈는 서명 키를 교체합니다. v0.6.3 이하 사용자는 v0.7.0 설치 파일을 한 번 직접 실행하세요. 기존 계정으로 로그인하면 전적·XP·코인을 그대로 사용합니다. 이후 업데이트는 새 키를 계속 사용합니다. 개인 키는 소스 저장소·게임 서버·배포 파일에 넣지 않습니다. 다른 PC의 개발과 빌드는 키 없이 가능하며, 공식 배포 서명에만 같은 개인 키가 필요합니다. 키를 매번 생성하지 마세요.

운영 서버에 2026-10-24 적용했습니다. 기존 프로필 5개와 경기 기록 25건을 보존하고 전체 데이터 백업 후 숙련 필드를 추가했습니다. 기존 계급은 보존하며 새 숙련 기록은 적용 이후부터 쌓입니다.

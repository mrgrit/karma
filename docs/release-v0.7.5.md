# v0.7.5 — F12 검은 스크린샷 수정

F12가 검은 화면이나 모니터 왼쪽 위를 저장하던 문제를 수정했습니다. 게임의 Direct3D 렌더링 프레임을 읽어 원래 JPEG 저장기로 전달합니다. 창 위치나 바탕화면 캡처에 의존하지 않습니다.

저장 위치: `App_Executables/Data/ScreenShot`.

검증: 격리된 실제 게임 엔진에서 F12를 두 번 실행하여 800×600 JPEG 두 장을 저장하고 게임 장면이 보이는 것을 직접 확인했습니다. 픽셀 변환 테스트에서 16/24/32비트 색상, 행 간격, 상하 방향과 패딩을 검증했습니다.

기존 계정·전적은 유지됩니다. 별도 런처 창은 게임 프레임에 포함되지 않습니다.

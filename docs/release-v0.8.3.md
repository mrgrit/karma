# v0.8.3

대기실 참가자 목록에 **서버 핑**을 표시합니다. 각 PC와 중앙 서버 사이의 왕복 지연시간이며 낮을수록 응답이 빠릅니다. 입장 후 자동으로 측정하고 약 3초마다 갱신합니다.

- `핑 12 ms`: 측정된 왕복 지연시간. 1ms 미만은 `<1 ms`로 표시합니다.
- `핑 측정 중`: 첫 응답 대기.
- `핑 응답 없음`: 5초 안에 응답하지 않음. 회복되면 숫자로 돌아옵니다.
- `핑 미지원`: 이전 서버 또는 클라이언트가 측정을 지원하지 않음.

핑 때문에 준비가 풀리거나 강제 퇴장되지 않으며 경기 중에는 대기실 측정을 중단합니다. 서버 3.9.1과 함께 사용합니다. 기존 자동 업데이트 서명키와 계정·전적·개인 설정을 유지합니다.

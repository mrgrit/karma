# v0.7.3 — 같은 버전 방 참가 차단 수정

v0.7.1~v0.7.2에서 같은 버전으로 만든 방도 방 목록에 ‘버전 다름’으로 표시되어 참가할 수 없던 오류를 수정했습니다. 방 목록이 이전 통신 규격 central5를 검사하고 실제 게임은 central6을 사용하던 불일치가 원인이었습니다.

방 목록의 참가 가능 여부·상태·오류 안내가 같은 통신 규격 상수를 사용하도록 통일했습니다. 실제 hello 및 대기실 장비 갱신이 사용하는 규격과의 일치 검사, 대기 중/진행 중 참가 허용, 서버 참가 제한 및 구형 규격 차단 회귀 테스트를 추가했습니다.

두 PC에서 게임과 실행기를 닫았다가 다시 열어 v0.7.3을 확인하세요. 서버와 게임 통신 규격은 바꾸지 않았으며 기존 계정·전적은 유지됩니다.

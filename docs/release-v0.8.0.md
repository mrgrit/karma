# v0.8.0 — 코인 구분과 운영 규정 동의

0.7.8 기반입니다. 이전 PC에서 적용한 숙련도·시나리오·맵 개방 및 입력/HUD 안정화 변경을 유지합니다.

- 가입 시 운영 규정 전문을 읽고 직접 동의해야 신청할 수 있습니다.
- 기존 계정도 서버가 재동의를 요구하면 규정을 표시합니다. 체크 없이 제출하거나 자동 동의하지 않습니다.
- 실행 도구의 코인 표시를 누르면 일당/한도·보너스·기본 상세를 확인할 수 있습니다. 게임 일시정지 메뉴에도 구분을 표시합니다.
- 차감 순서는 일당 → 보너스 → 기본입니다. 코인 금액과 지급·거래 권한은 서버에서 결정합니다.

이번 버전부터 새 업데이트 서명키를 사용합니다. **모든 PC에서 v0.8.0 설치 파일을 한 번 직접 실행해야 합니다.** 이전 버전의 자동 업데이트로는 새 키를 신뢰할 수 없습니다. 기존 설치 경로에 덮어 설치하면 계정·전적·코인 등 서버 기록과 개인 설정이 유지됩니다. 이후 배포는 이 PC에 보관된 새 키로 서명하며 자동 업데이트됩니다.

- 자정 일당 한도는 훈련병 10개부터 진급 단계마다 +2개입니다.
- 30분마다 1개씩 추가 회복하되 모든 계급이 하루 합계 10개까지만 받습니다. 재접속·진급·리셋으로 추가 회복 한도가 초기화되지 않습니다.
- 내 코인 상세에서 오늘 추가 충전량과 남은 충전량을 확인할 수 있습니다.
- 재설치 후에는 이전 키로 서명한 미완료 업데이트 복구 작업을 불러오지 않습니다. 기존 개인 파일은 삭제하지 않습니다.

업데이트 서명은 Windows 게시자 코드 서명과 다르므로 Windows SmartScreen 안내가 계속 표시될 수 있습니다.

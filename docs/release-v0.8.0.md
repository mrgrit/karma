# v0.8.0 — 코인 구분과 운영 규정 동의

0.7.8 기반입니다. 이전 PC에서 적용한 숙련도·시나리오·맵 개방 및 입력/HUD 안정화 변경을 유지합니다.

- 가입 시 운영 규정 전문을 읽고 직접 동의해야 신청할 수 있습니다.
- 기존 계정도 서버가 재동의를 요구하면 규정을 표시합니다. 체크 없이 제출하거나 자동 동의하지 않습니다.
- 실행 도구의 코인 표시를 누르면 일당/한도·보너스·기본 상세를 확인할 수 있습니다. 게임 일시정지 메뉴에도 구분을 표시합니다.
- 차감 순서는 일당 → 보너스 → 기본입니다. 코인 금액과 지급·거래 권한은 서버에서 결정합니다.

배포에는 현재 0.7.8 클라이언트가 신뢰하는 개인 서명키로 서명한 업데이트가 필요합니다. 키가 준비되기 전에는 새 설치 파일·자동 업데이트를 공개하지 않습니다. 구버전에서도 웹 대시보드의 규정 동의를 완료한 계정은 게임을 이용할 수 있습니다.

# 카르마 LAN v0.8.5

사망·라운드 전환·채팅 중 발생할 수 있는 연결 종료 경로를 수정하고 팀전 아군 관전을 추가했습니다. 서버 3.9.3과 함께 배포합니다.

## 연결 안정성

- 다른 참가자의 개별 퇴장 메시지로 남은 모든 클라이언트가 종료되지 않습니다. 경기 종료는 중앙 서버가 판단합니다.
- 채팅·사망 알림·상태 파일을 동시에 읽고 쓸 때 Windows 파일 잠금 오류가 통신 연결 종료로 전파되지 않습니다. 읽기는 공유 접근을 사용하며 쓰기는 최신 상태를 보관해 재시도합니다.
- 사망 시 부정확한 선택적 무기 드롭 정보는 해당 드롭만 버립니다. 너무 이른 리스폰 상태가 서버 인벤토리를 변경하지 않습니다. 방을 떠난 참가자에게 뒤늦게 도착한 피격으로 공격자의 연결을 끊지 않습니다.
- 종료 시점의 네이티브 호출 위치·창 메시지·채팅 상태, 서버 연결 종료 이유를 기록해 후속 분석을 돕습니다.

## 팀전 아군 관전

- 사망하면 살아 있는 같은 팀원의 위치·시선·확대 배율을 따라갑니다. ←/→ 키로 아군을 전환하고, 대상이 사망하거나 나가면 남은 아군을 선택합니다.
- 화면 아래에 대상 이름·체력·현재 무기·탄약을 표시합니다. 채팅이나 메뉴를 조작하는 동안 방향키는 관전 대상을 바꾸지 않습니다.
- 다음 라운드에 본인 시점으로 복귀합니다. 개인 데스매치의 10초 리스폰은 유지합니다.
- 현재 관전은 아군의 1인칭 카메라와 상태 표시입니다. 손에 든 총의 모델·재장전 애니메이션까지 영상처럼 복제하지는 않습니다. 사망한 본인 캐릭터의 위치·체력·인벤토리는 변경하지 않습니다.

## 업데이트와 검증

v0.8.0 이상은 다음 실행 시 기존 서명키로 자동 업데이트합니다. 이전 버전은 최신 설치 파일로 재설치합니다. 기존 계정·코인·전적은 유지합니다.

서버 수명주기 회귀 검사, Windows 실제 파일 공유 충돌 검사, 숨김 원본 게임 4개를 이용한 사망·채팅·라운드 전환·관전 검사를 수행했습니다. 이는 한 PC에서 원본 엔진을 여러 개 실행한 검사이며, 해당 학생 PC의 최초 종료 원인까지 확정한 것은 아닙니다.

# v0.7.4 — 휠 버튼 종료와 F12 캡처 위치 수정

- 총을 든 채 휠 버튼을 눌러 수류탄을 바로 던지면, 존재하지 않는 옛 온라인 계정 정보를 읽어 게임이 종료되던 오류를 수정했습니다. 수류탄 선택·보유량·탄약 검사와 원래 무기로 돌아오는 동작은 유지합니다.
- 종료된 게임에 뒤늦게 도착한 메시지가 ‘Script is destroyed’라는 후속 오류로 원래 종료 원인을 덮어쓰지 않도록 수정했습니다.
- F12 스크린샷이 모니터 왼쪽 위를 찍던 원본 코드를 보정했습니다. 게임 창의 실제 화면 영역과 현재 크기로 JPG를 저장합니다. 창 위치, 확대 배율 및 음수 좌표의 보조 모니터를 고려합니다. 원본 저장 폴더·파일명은 유지합니다.

검증: 휠 입력으로 실제 엔진 종료를 재현한 뒤, 수정본에서 수류탄 발사·총 복귀·탄약 소진·수류탄 미보유 상태를 검사했습니다. 클라이언트 회귀 테스트와 캡처 좌표·크기·DPI·스레드 범위 테스트를 통과했습니다. 실제 저장 이미지의 육안 확인은 수행하지 못했습니다.

게임과 실행기를 닫았다가 다시 열어 v0.7.4를 확인하세요. 서버 재시작이나 계정·전적 변경은 없습니다.

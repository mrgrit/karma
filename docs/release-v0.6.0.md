# v0.6.0 — 공식 배포 자동 업데이트

설치 EXE 하나로 게임과 런타임을 설치합니다. v0.5.2 이전 사용자는 이 버전을 한 번 설치해야 자동 업데이트가 활성화됩니다.

- 실행할 때 학과 LAN 서버의 서명된 배포 정보를 확인합니다. 버전이 같아도 공식 파일과 해시가 다르면 복구합니다.
- 변경·누락된 파일만 받으며 RSA 서명, SHA-256과 파일 크기를 검증한 뒤 교체합니다. 설치 폴더 밖의 경로와 개인 설정 경로는 허용하지 않습니다.
- 게임 또는 다른 카르마 프로세스가 실행 중이면 업데이트를 기다립니다. 게임을 강제로 종료하지 않습니다.
- 교체 실패와 업데이트 도중 프로세스 종료는 보관한 백업으로 복구합니다. 로그인·전적·코인·개인 장비 설정은 보존합니다.
- LAN 배포 서버(192.168.12.100:29021)에 연결할 수 없거나 검증에 실패하면 재시도/닫기를 안내하며 게임을 실행하지 않습니다.
- 설치 후 정상적인 실행 파일 자체가 삭제되거나 실행 불능이 된 경우에는 설치 EXE로 복구해야 합니다. 소스만 수정한 개발 빌드도 공식 배포와 다르면 복구 대상입니다.

신규 일반 계정의 첫 지갑 지급은 공동 금고에서 100 KARMA입니다. 기존 지급 이력이 있으면 중복 지급하지 않습니다. 관리자 승인 정책과 현재 게임 규칙은 유지됩니다.

검증: 기존 클라이언트 TCP·입력·전투·이름·폰트 회귀 검사, 서명/해시/경로 거부, 동일 버전 손상 복구, 교체 실패 롤백, 실제 자식 프로세스 중단 후 복구, 실행 중 프로세스 보호.

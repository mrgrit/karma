# v0.6.3 — 첫 접속 음악 한 번 재생

실행기를 연 뒤 첫 계정 접속이 성공하면 기존 게임의 `App_Executables/Data/Sound/Music/menu.wma`를 한 번 재생합니다. 저장된 로그인으로 자동 접속할 때도 동일합니다. 음악 길이는 약 1분 17초이며 반복 재생하지 않습니다.

- 전적 새로고침, 서버 재접속, 경기 종료 후 대기실 복귀로 다시 재생하지 않습니다. 실행기를 완전히 닫고 새로 열면 첫 접속 때 다시 한 번 재생합니다.
- 오른쪽 위 **음악 끄기**로 즉시 멈출 수 있습니다. 게임 시작, 로그아웃, 실행기 종료 시에도 멈춥니다. 재생 중 게임 실행 감지는 최대 약 1.2초 간격입니다.
- 초기 음악 볼륨은 25%입니다. 기존 원본 음악을 로컬에서 재생하므로 음악을 위한 별도 다운로드나 브라우저가 필요하지 않습니다.
- 음악 파일이나 재생 장치에 문제가 있으면 실행기 이용은 계속 가능하며, 반복 재시도하지 않습니다. 음악 기능은 키보드·마우스를 점유하지 않습니다.

검증: 최초 접속·반복 갱신·곡 종료·수동 중지·게임 시작·종료·장치 오류의 수명 주기 검사, Windows MCI에서 원본 WMA의 실제 디코딩/시간 진행/자동 종료(76,624ms, 무음 검사), 전체 클라이언트 회귀 검사, 실행기·업데이터 빌드. 브라우저의 YouTube 음원을 내려받거나 배포 파일에 추가하지 않았습니다.

기존 사용자는 게임과 실행기를 닫고 다시 열면 자동 업데이트됩니다.

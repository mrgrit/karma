# v0.7.7 — 대기실 방장 맵·방 설정 변경

방장에게 대기실의 ‘방 설정 · 맵 변경’ 버튼을 제공합니다. 방을 새로 만들지 않고 맵, 방 이름, 대전 방식, 최대 인원, 목표 킬/승수와 제한 시간을 바꿀 수 있습니다. 현재 맵 이름도 대기실에 표시합니다.

변경 시 모든 참가자의 준비가 해제됩니다. 모두 다시 준비하면 새 설정으로 시작합니다. 현재 참가자보다 작은 정원, 맵의 지원 인원 초과, 비공개 맵 권한 우회, 잘못된 팀전 정원은 거절합니다. 시작·이용료 처리 중 또는 경기 중에는 변경할 수 없습니다. 방장 이전과 오래된 설정 창도 서버에서 검증합니다.

서버 3.7.3과 함께 적용합니다. 계정·전적·공개 맵 설정·맵 구조·스폰은 유지합니다. v0.7.6 사용자는 런처를 다시 실행해 업데이트하세요.

검증: 실제 TCP 참가자 3명의 변경·준비 초기화·방장 이전·새 맵/모드 시작, 결제 중 변경 거절, 클라이언트 상태 전달, 숨김 WinForms 방 설정·대기실 렌더링, 서버·클라이언트 회귀 테스트.

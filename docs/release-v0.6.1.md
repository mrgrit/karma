# v0.6.1 — 대전 시작 시 종료 방지와 Esc 확인

- 게임 첫 프레임과 창 전환 직후 남아 있는 Esc/F10 눌림 상태는 새 입력으로 처리하지 않습니다. Win32와 DirectInput 각각에서 놓인 상태를 확인한 뒤 새 입력을 받습니다.
- Esc는 즉시 종료하지 않고 “대전을 종료하시겠습니까?” 확인창을 엽니다. 사격 연습에도 적용합니다. 마우스 점유를 해제하며, 기본 Enter·계속하기·Esc·F10·창 닫기는 복귀입니다. 종료 버튼을 선택해야 나갑니다.
- F10 메뉴의 게임 종료 버튼도 확인을 묻습니다. LAN에서는 확인 중에도 대전과 경기 시간이 진행됩니다.
- F10 창 메시지를 처리할 때 관계없는 Esc 비동기 상태를 섞지 않습니다.

v0.6.0 설치자는 게임과 실행기를 완전히 닫은 뒤 다시 실행하면 서명된 v0.6.1 파일을 자동으로 받습니다. 새 PC에는 v0.6.1 설치 파일을 배포하세요.

검증: 기존 클라이언트 전체 회귀 검사, 시작/초점 전환/키 반복/입력 경로별 재현 검사, 실제 WinForms의 확인·취소·기본 Enter·Esc·창 닫기 검사, 한 PC에서 원본 엔진 두 개와 별도 테스트 서버로 Factory 대기실 준비→시작→잘못된 Esc 무시→종료 취소→F10→명시적 종료를 확인했습니다. 이 버전으로 학생 PC와 실제 두 PC 재대전은 아직 확인하지 않았습니다.

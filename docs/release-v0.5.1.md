# v0.5.1 — 준비 완료 대기실·방 이름·무기 버리기 수정

방장은 방 이름을 입력해서 방을 만듭니다. 참가자는 먼저 대기실에 **준비 중**으로 등록되고 장비를 바꿀 수 있습니다. 최소 인원과 팀 조건을 만족하며 현재 참가자 전원이 **준비 완료**를 눌렀을 때만 방장의 **대전 시작** 버튼이 활성화됩니다.

- **장비 설정**을 열면 서버가 준비 해제를 확인한 뒤 창을 엽니다. 저장하거나 취소한 뒤에도 준비 완료를 다시 눌러야 합니다. 참가자가 장비를 고르는 동안 방장이 먼저 시작할 수 없습니다.
- 방 이름을 방 목록과 대기실에 표시합니다. 참가 직전 방을 다시 조회하고, 닫힌 방이나 참가할 수 없는 방은 목록을 갱신해 안내합니다.
- 진행 중인 개인 데스매치는 빈자리가 있을 때 장비를 정한 뒤 중간 참가하는 기존 방식을 유지합니다.

사격한 뒤 G로 무기를 버리면 “상대와의 연결이 끊겨 대전을 종료했습니다.”가 나타나던 문제를 수정했습니다. 버리기는 이미 승인됐지만 이전 무기의 사격 정보가 다시 전송되어 서버가 연결을 종료하던 경우였습니다.

- 버리기 승인 후에는 제거한 무기의 과거 사격 정보를 더 이상 전송하지 않습니다.
- 장비 변경 전의 대기 상태와 같은 사격의 중복 전송을 정리합니다.
- G 버리기·E 줍기, 서버 승인, 인벤토리 점수 제한과 탄약 보존은 유지됩니다. 이미 발사된 포탄의 피해 증거와 다음 사격 번호도 유지됩니다.

전체 클라이언트 검사, 대기실 준비/장비 변경/방장 권한 검사와 Rescue 전장의 원본 게임 두 프로세스·실제 TCP 연결 검사를 통과했습니다. 두 참가자의 명시적인 준비 완료 후 시작하고, 양쪽 사격→G→새 무기 사격→E 재획득에서 PPS43의 탄약 35/122와 연결 유지를 확인했습니다. 상세 범위는 [검증 기록](../VALIDATION.md)에 있습니다.

기존 설치 위치에 v0.5.1 설치 파일을 실행하면 업데이트됩니다. 개인 설정과 로그인 정보는 유지됩니다. 서버와 상대 PC도 관리자가 제공한 최신 버전을 사용하세요.

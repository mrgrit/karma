# v0.7.8 — 무기 안내 파일 충돌로 인한 실행 도구 종료 방지

G키 무기 버리기·E키 줍기 안내를 HUD가 읽는 동안 파일 쓰기가 잠기면 실행 도구가 종료될 수 있던 경로를 수정했습니다. HUD는 읽기/쓰기를 공유하고, 일시적인 안내 파일 저장 실패는 게임 통신을 종료하지 않습니다. 이후 안내는 다시 표시됩니다.

예상치 못한 실행 도구 오류는 last-session.log에 원인과 스택을 남기도록 보강했습니다. Windows 실제 파일 잠금 회귀 테스트로 기존 쓰기 오류와 수정 후 생존·복구를 확인했습니다.

상대 PC에서 제공한 로그에는 종료 원인이 남아 있지 않아, 이번 종료가 이 경로인지 확정하지 않았습니다. 실제 게임 엔진 두 개를 사용한 G 버리기·E 다시 줍기와 연결 유지 검사도 통과했습니다. 서버 재시작은 필요 없으며 계정·전적은 유지됩니다.

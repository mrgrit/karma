# 카르마 LAN v0.8.4

회복 장비 칸을 `회복·방어 장비`로 확장했습니다. 구급약 대신 방탄복이나 헬멧을 넣어 기존 방어 장비와 함께 착용할 수 있습니다. 모든 병과·계급에 적용되며, 전체 7칸과 캐릭터·계급별 점수 한도는 유지됩니다.

방탄복은 50점, 헬멧은 100점입니다. 같은 장비 중복 착용과 쌍포에 방어구를 추가하는 조합은 허용하지 않습니다. 기존 저장 장비와 구급약 선택은 유지됩니다.

서버 3.9.2에서 같은 규칙을 검증합니다. v0.8.x 실행기를 다시 열면 기존 서명키로 검증한 자동 업데이트를 받을 수 있습니다.

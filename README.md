# Karma LAN 클라이언트

Karma290 원본 게임에 Windows 실행기, 입력 호환성 수정, 2인 LAN 대전과 중앙 서버 계정을 연결한 실험 버전입니다.

## 설치와 실행

1. [Releases](https://github.com/mrgrit/karma/releases)의 **Karma-LAN-v0.2.0.zip**을 받습니다.
2. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다.
3. `Karma/KarmaLauncher.exe`를 실행합니다. Runtime 폴더가 포함되어 있으므로 다른 PC에 REA를 설치할 필요는 없습니다.
4. `로그인/계정`에서 회원가입 또는 로그인합니다. 현재 LAN 서버는 이메일 인증 없이 바로 가입됩니다.
5. 캐릭터를 고르고 `장비·계급`에서 초기 무기를 선택합니다.
6. 방장은 `LAN 방 만들기 (2인)`, 상대는 `LAN 참가 (2인)`을 선택합니다. 양쪽 서버 주소는 `192.168.12.100`, 게임 포트는 `29020`입니다. 방장이 알려 준 6자리 방 코드를 참가자가 입력하면 시작됩니다.

실행 파일 하나만 복사하면 동작하지 않습니다. 압축 해제한 Karma 폴더 전체를 옮기세요. `App_Executables`의 EXE를 직접 실행하면 호환성 수정이 적용되지 않습니다.

## 현재 게임 규칙

- 원본 캐릭터·무기와 Mass of Winter 전장에서 1:1 대전합니다.
- 캐릭터별 허용 무기와 장비 점수가 다릅니다. 초기 7개 슬롯은 해당 캐릭터의 계급 예산 안에서 선택합니다.
- 경험치 0 / 100 / 300 / 600 / 1000에서 계급이 올라가며 장비 예산 보너스는 0 / 100 / 200 / 300 / 400입니다. 처치 25 XP, 확인된 사망 5 XP를 기록합니다.
- 사망 시 들고 있던 무기가 바닥에 남습니다. 가까이 접근하면 장비 예산이 허용하는 범위에서 획득하며, 탄창과 예비탄은 사망 당시의 수량 그대로입니다. 같은 무기를 주워도 탄약을 새 탄창으로 채우지 않습니다.
- 10킬 또는 10분에 경기가 끝납니다. 동점은 무승부이며, 시작 후 이탈하면 기권패로 기록합니다.
- W/A/S/D 이동, 마우스 조준, 왼쪽 클릭 사격, R 재장전, 숫자 1~7 무기 변경.
- F10은 자기 입력과 마우스 점유를 해제하는 메뉴입니다. LAN에서는 상대와 경기 시간이 계속 진행됩니다. Esc는 대전을 종료합니다.

로컬 맵·사격 연습·AI 1명 시험판도 실행기에 남아 있습니다. 현재 중앙 LAN 클라이언트는 **2인용**입니다. 서버의 20개 방 × 8명 모의 통신 검사는 실제 게임의 4:4 지원을 의미하지 않습니다. 다른 전장 LAN, 3인 이상, 인터넷 매칭, 장시간 안정성은 후속 범위입니다.

## 계정과 대시보드

[LAN 대시보드](https://192.168.12.100:29021)에서 본인 계급·장비·승패·킬데스, 리더보드와 최근 활동을 봅니다. 관리자는 사용자 목록에서 경험치·전적·장비·사용 중지 상태를 관리합니다.

클라이언트는 배포된 공개 인증서 `server-ca.pem`으로 서버를 검증합니다. 서버 개인키와 사용자 비밀번호는 배포 파일에 없습니다. 브라우저는 내부 서버의 자체 발급 인증서를 별도로 확인할 수 있으며, 경고가 표시되면 서버 주소와 인증서를 사용자가 확인해야 합니다.

로그인 토큰은 Windows 사용자별 `%LOCALAPPDATA%/KarmaLAN/servers`에 저장되며 배포본에는 포함되지 않습니다. 실행기 `로그인/계정`에서 로그아웃할 수 있습니다. 가입 이메일 인증은 현재 꺼져 있으며 추후 SMTP 설정으로 켤 수 있습니다.

서버 코드와 운영 방법: [mrgrit/karma_server](https://github.com/mrgrit/karma_server).

## 소스와 빌드

Git 저장소에는 실행기 EXE, C#·JavaScript 코드, 카탈로그, 네이티브 어댑터 생성 소스와 테스트가 있습니다. 전체 게임 리소스와 Node/Frida 런타임은 Release ZIP에 포함됩니다. Git clone만으로는 게임을 실행할 수 없습니다.

```powershell
# Windows .NET Framework C# 컴파일러 사용
.\build.ps1

# Node.js 20 이상: 게임 실행 없이 코드·TCP·입력 상태 검사
npm test

# 네이티브 LAN 어댑터 다시 생성 (Python 3)
python tools/build_native.py
```

`client/Launcher`가 실제 배포 코드, `native`가 LAN 네이티브 어댑터 원본, `tests`가 테스트입니다. `build.ps1 -GameRoot C:\Games\Karma`로 압축 해제한 게임 폴더의 실행기와 코드만 갱신할 수 있습니다.

검증 범위는 [VALIDATION.md](VALIDATION.md), 포함 런타임 고지는 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)를 참고하세요. 게임 리소스와 제3자 구성 요소의 권리는 각 권리자에게 있습니다.
